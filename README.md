### 🛠️ Редактор

- **Перетаскивание** мышью или пальцем
- **Точный сдвиг** стрелками клавиатуры (`Shift` = крупный шаг)
- **Zoom** от 10% до 300%
- **Сетка** 100×100 px
- **Safe-зона** 5% от края — проверка, что элементы не обрежутся
- **Привязка** к сетке, краям и другим элементам
- **Направляющие** по центру холста
- **Undo / Redo** на 40 шагов
- **Мультивыделение** (Shift+клик)
- **Копирование стиля** между элементами
- **Дублирование** (`Ctrl+D`)
- **Зеркалирование** по горизонтали

### 📦 Экспорт

| Формат | Для чего |
|--------|----------|
| **PNG** | Полное разрешение, прозрачность — для OBS как Источник → Изображение |
| **SVG** | Векторное качество на любом размере |
| **HTML** | Виджет для OBS Browser Source с живой анимацией алертов |
| **GIF** | Анимированный с пульсацией |
| **JSON** | Сохранение проекта для возврата |
